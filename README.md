
# AI Movie Recommendation Engine

## Project Description

The AI Movie Recommendation Engine is a Python-based
Machine Learning application that recommends movies
based on user interests.

It uses Content-Based Filtering to identify similar
movies based on their genres and descriptions.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- TF-IDF Vectorization
- Cosine Similarity

## Features

1. Select your favorite movie.
2. Get similar movie recommendations.
3. Choose the number of recommendations.
4. View movie genres and descriptions.
5. Display similarity scores.
6. Interactive web application.

## Installation

Step 1: Install Python.

Step 2: Open the project folder in VS Code.

Step 3: Install the required libraries.

pip install -r requirements.txt

Step 4: Run the application.

streamlit run app.py

Step 5: Open the local URL displayed in the terminal.

Usually:
http://localhost:8501

## Machine Learning Algorithm

Content-Based Filtering

TF-IDF Vectorization

Cosine Similarity
